## Research highlights

| **Budget-Aware Adaptive Mutation Feedback** | Leakage-controlled, resource-tracked LLM unit-test generation with Defects4J and Bugs.jar validation | Preliminary empirical study |
| **Cross-Domain Scientific Text Analysis** | Source-label-informed, target-unsupervised AI-vs-human abstract analysis using TF-IDF, SciBERT, UMAP, and clustering | Ongoing research |
| **AI Usage Constraints and Learning** | PLS-SEM study of frustration, tool switching, prompting skill, and perceived learning effectiveness using **320 responses** | Exploratory research |
